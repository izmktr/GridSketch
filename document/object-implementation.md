# オブジェクト編集の実装記録

2026-10-12。設計草案に対する今回の実装範囲を記録する。

## 実装した構成

- 保存単位はSceneDocument（v3）、ルートはキャンバス。既存Documentはv1/v2の読込・移行用に保持。
- キャンバス、グリッド、グループ、罫線、グリッド文字、セル塗り、画像、フリーテキスト、ライン、図形。
- レイヤーとプロパティは右側のサイズ変更可能なパネル。親の変更、並べ替え、グループ化・解除、名前、表示、ロックを操作可能。
- マスへの配置と集合オブジェクトの内部編集。描画順は同階層の上ほど手前。
- 自動出力範囲、固定出力範囲、背景、DPIを保持。PNG出力は編集ガイドを含まない。
- 新規キャンバスの設定とプリセット付きグリッド追加。
- Undo/Redo、既存のファイルメニュー・最近使ったファイルを維持。

## 未決定だった項目に対する今回の選択

- 1キャンバスに複数グリッドを配置可能。回転中心は各オブジェクトの左上。拡大縮小変形は導入せず、マス寸法や画像・図形サイズを編集する。
- 罫線・グリッド文字・セル塗り・マス配置画像はグリッド直下で管理し、独立の移動・回転を制限。
- 外枠・内側・すべての罫線プリセットはマス数に追従。個別編集時に辺集合へ変換する。一括操作は明示的な追加／削除。
- グリッド変更時は旧形式から移行した外枠・内枠も新しいマス数に追従する。個別罫線は右端・下端の辺を新しい外周へ移し、範囲外の辺を切り詰める。文字・マス配置画像・セル塗りが範囲外になる変更は対象名を示して拒否し、配置内容を保持する。サイズ変更はUndoで復元可能。
- セル塗りは1オブジェクト1色。入力除外が設定されたセル塗りの集合で文字入力を制限し、非表示でもその意味は残す。
- 文字はUnicodeのテキスト要素ごとに1マス。制御文字・改行は拒否、空白は1マス。小書き文字も1マス。全体を検証後に一括確定し、途中まで適用しない。
- 同じ文字を入力する交差は維持し、異なる文字の上書きは確認。入力衝突の判定は選択中の文字オブジェクト内で行い、別の文字レイヤーとは独立。
- 旧文字のセル別フォント・サイズを移行用に保持。新規文字はオブジェクト共通書式を使う。
- 画像の余白はグリッド共通、自由配置画像は指定の矩形内へ縦横比を保って収める。
- ラインのマス中央スナップは配置時のみ。曲線の制御点と回転は数値で指定する。
- 自動キャンバスは表示されたグリッドの領域を含める。個別罫線が0本でも設定された線幅の余白を確保し、最初の辺の追加で範囲が動くのを防ぐ。
- 固定サイズは出力原点を保持。自動から固定へ切替時は計算済みの範囲を引き継ぐ。
- キャンバスは自動／固定を持つ最終出力範囲。固定サイズはCanvasUnit（px／mm、既存ファイルはpx）と幅・高さで保存する。mm指定時はdpiから四捨五入で画素数を計算し、px指定と自動サイズではdpiはメタデータと物理サイズ換算に使う。PNGはキャンバスの画素数で出力。空の自動キャンバスは800×600に設定余白を加えた範囲。PDFは1キャンバス1ページで出力し、mm指定は正確な物理寸法を保持する。文字を輪郭化し、図形と罫線はベクターとして出力。PDF画像設定はプロジェクトに保存し、印刷用／軽量／品質優先とカスタム設定を提供する。背景はキャンバスに従い、画像の透明度も保持する。
- 旧形式の移行では固定キャンバスを作り、旧出力サイズ・画像余白・文字書式・重なり順を保持する。旧ファイルを読むだけでは保存しない。

## 今回の対象外

グリッド画像、複数桁の問題番号、独立したフローティングウィンドウ、複数オブジェクトの同時選択、拡大縮小変形、回転ハンドル・曲線制御点のドラッグ、別グリッドへのマス配置データの移し替え。

これらは設計草案の拡張候補として残す。利用方法はREADMEを参照。
